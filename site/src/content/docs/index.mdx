pageslens reads a Power Pages site from the files in git: a download from `pac pages download-code-site` or `pac pages download`, or an unpacked solution that holds the site. It needs no Dataverse connection and no agent: the same folder gives the same output every run.

```bash
npx pageslens lint path/to/site
```

<CardGrid>
  <Card title="Lint" icon="warning">

  <Card title="Docs" icon="document">
