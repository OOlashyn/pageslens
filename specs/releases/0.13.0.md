## pageslens 0.13.0

A documentation site: [pageslens.olashyn.dev](https://pageslens.olashyn.dev). It has the same text as the Markdown in the repository, with search, and the links in pageslens's output now point at it. What pageslens checks hasn't changed.

### New

- **The docs site** at [pageslens.olashyn.dev](https://pageslens.olashyn.dev): getting started, a page per command, every lint rule, and guides for CI, an ALM workflow, Azure Pipelines and coding agents. It's built from `docs/` and `rules/` and deployed for each release, so it describes the version on npm. `pageslens explain <rule>` still prints the same rule pages in the terminal.

### Changed

- **Links in the output point at the site.** SARIF help links and the `docs` link on each lint finding in `--format json` go to the site's pages instead of the Markdown on GitHub's `main`, which could be ahead of the version you run:

  | Output                              | Link                                                    |
  | ----------------------------------- | ------------------------------------------------------- |
  | A lint finding (JSON `docs`, SARIF) | `https://pageslens.olashyn.dev/rules/<rule>/`           |
  | A policy statement (SARIF)          | `https://pageslens.olashyn.dev/commands/test/`          |
  | An align finding (SARIF)            | `https://pageslens.olashyn.dev/commands/align/#<check>` |

- **The README is shorter.** It keeps what pageslens does, the quick start and a table of the commands. The rest moved to pages in `docs/`, which the site shows: getting started (the site folder, solutions, deployment settings), `lint` and its configuration, `docs`, [In CI](https://pageslens.olashyn.dev/guides/ci/) and [Using pageslens with an agent](https://pageslens.olashyn.dev/guides/agents/). Links to the README's "Using pageslens with an agent" heading still land, with a link on to the page.

- **The package's homepage** on npm is the site.

### Upgrading

Findings, policy results, access changes and exit codes are the same as in 0.12.0.

If you match on the help links in SARIF or on the `docs` field in lint's JSON, update the pattern. The JSON outputs' `version` is still 1. Alerts already in code scanning keep their old links to GitHub, which still work.

If your `AGENTS.md` points an agent at the README's agent section, you can point it at https://pageslens.olashyn.dev/guides/agents/ instead.

```bash
npm install --save-dev pageslens@0.13.0
```

Update the action to `OOlashyn/pageslens@v0.13.0`.
