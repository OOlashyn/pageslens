## pageslens 0.2.0

Classic Power Pages sites, ignore entries in the config, and child table permissions that inherit their parent's roles.

### New

- **Classic sites.** `lint` and `docs` now read the folder written by `pac pages download`, not only the `.powerpages-site` folder from `pac pages download-code-site`. Point pageslens at the folder that contains `website.yml`. The layout is the same with `--modelVersion 1` and `2`, and pageslens tells the two layouts apart by the keys in `website.yml`. Verified on an enhanced data model site; a standard data model site isn't verified yet. (#6)
- **Ignore findings in `pageslens.config.yaml`.** An `ignore` entry leaves out findings by file glob, by record GUID, or both, optionally for some rules only, with a `reason` for reviewers. Use record GUIDs on classic sites, where all roles or site settings share one file. Ignored findings are still counted: `1 ignored` in the text summary and `ignored` in JSON. (#8)

  ```yaml
  ignore:
    - rules: [global-write-anonymous]
      records: [3453215b-d450-4073-a12c-88aa8a248b81]
      reason: Public contact form creates feedback records
  ```

- **JSON Schema for the config.** Add this line to the top of `pageslens.config.yaml` for completion and validation in editors with the YAML language server:

  ```yaml
  # yaml-language-server: $schema=https://raw.githubusercontent.com/OOlashyn/pageslens/main/pageslens.config.schema.json
  ```

  The schema also ships in the package at `node_modules/pageslens/pageslens.config.schema.json`. (#8)

### Changed

- **Child table permissions inherit their parent's web roles.** The design studio creates child (Parent scope) permissions without web roles of their own; at runtime they use the parent's. pageslens now does the same. `permission-no-role` no longer flags these permissions, and the access matrix, Web API callers and diagram now include their grants. If the parent chain gives a child no role, `parent-chain-broken` reports it. (#5)
- **JSON output** has a new top-level `ignored` count. The format version stays `1`, because nothing was removed or changed.

### Upgrading

Nothing that worked in 0.1.0 needs changing. You may see fewer `permission-no-role` warnings and more grants in generated docs, both from child permissions that now inherit roles. If you commit the output of `pageslens docs`, regenerate it.

```bash
npm install --save-dev pageslens@0.2.0
```
