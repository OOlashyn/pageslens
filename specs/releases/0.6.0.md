## pageslens 0.6.0

<!-- Draft: page access rules for classic sites still to come; write the summary line and the New section when they land. -->

### Fixed

- **Inactive records are left out.** Downloads include records that are inactive in Dataverse (`statecode: 1`), and pageslens read them as active. An inactive table permission set off `global-write-anonymous` and other rules, and showed up in the access matrix, in `test` and in `diff`. Now inactive table permissions, web roles, site settings, page access rules and website access records take part in nothing, as in Power Pages. `docs` says how many were left out. In `diff`, deactivating a record reads as removing it (`(deactivated)`), and activating one as adding it (`(activated)`). `permission-no-role` and `parent-chain-broken` say when the role or parent they point at is inactive.
- **GitHub Action:** the access-changes comment now compares the pull request's own head commit with the merge base, as GitHub's diff does. Before, it named the merge commit that `actions/checkout` creates for a pull request, which isn't one of the pull request's commits. The changes it found were the same.
- **`pageslens diff`:** a ref that is a commit id is shown once, short (`a1b2c3d`), instead of in full followed by the short id.

### Upgrading

Update the action to `OOlashyn/pageslens@v0.6.0`.

```bash
npm install --save-dev pageslens@0.6.0
```
